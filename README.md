# Ballito Creator Studio – Pricing Strategy Lab

Interactive Streamlit app to model **membership tiers** and **casual studio bookings** (full day, half day, 2-hour), breakeven, revenue, margins, and cost curves for Ballito Creator Studio.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Sign in at [share.streamlit.io](https://share.streamlit.io) with your GitHub account.
2. Click **New app**.
3. Select repository **SEANCODING123/ballito_pricing_app**, branch **master** (or your deploy branch), and main file **app.py**.
4. Confirm **requirements.txt** is at the repo root (Streamlit installs dependencies automatically).
5. Click **Deploy**.

No extra secrets or environment variables are required for this app.
